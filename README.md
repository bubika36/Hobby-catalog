Alap koncepcióként egy weboldalt képzeltünk el, ahol különböző sport, kulturális és szociális egyesületek feltölthetik elérhetőségeiket, weboldalaikat, áraikat és értékeléseiket, valamint egy bemutatkozást magukról, a számukra létrehozott felületen. Miután az adatbázisunkat feltöltöttük ezekkel az adatokkal (a továbbiakban is bővíthető lesz), elérhető lesz a felhasználók számára is, akik érdeklődésük alapján megtalálhatják a hozzájuk legközelebb eső, vagy legjobban értékelt klubbokat.
A platform célja, hogy minden ember megtalálhassa a számára kedves tevékenységet kategóriákra bontva, anélkül, hogy egy egész napos keresésbe teljen, mindezt saját pénztárcájukhoz és szabadidejükhöz mérve.

Funkciók, amiket szeretnénk megvalósítani: 

térkép integrálása, hogy térképen is látható legyen a klubok helye, a keresést végző személytől nézve

iframe, ahol az adott klubok weboldalai megjelennek

szűrők készítése, ami megkönnyíti a keresést

chat funkció a felhasználók számára (az adott hobbikhoz tartozó külön chat, a hasonló érdekeltségű emberek számára)
